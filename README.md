# Numerical Optimization & Modeling

**Course:** MATH 311 – University of Alabama  
**Language:** Python  
**Libraries:** NumPy, Matplotlib

## Project Overview
This project explores numerical optimization methods using Python. The goal was to implement and compare different optimization algorithms and examine how they approach a solution.

## Methods
- Implemented gradient descent, momentum, and Adam optimization algorithms.
- Compared how the algorithms converge toward a solution.
- Used Python to visualize and evaluate optimization results.

## Skills Demonstrated
- Python programming
- Numerical optimization
- Algorithm implementation
- Data visualization
- Numerical analysis
